# Frequently asked questions

## Is this a complete full-stack application?
No. It is a catalog, reproducible source checkout utility and build prompt. An agent must implement and qualify a product.

## Can Kotlin write Solana smart contracts?
Kotlin is used here for Android/JVM clients. Solana on-chain programs use separate chain-specific tooling, commonly Rust. Neo/JVM and Corda resources do not make Kotlin a universal contract language.

## Does Compose Multiplatform make every wallet work on every platform?
No. Check UI, network, cryptography and wallet transports per target. Android MWA qualification is separate from web or iOS wallet integration.

## Does IPFS encrypt private documents?
No automatic privacy guarantee is implied. Define encryption, gateway access and retention before uploading private material.

## Must users root their phone?
No. Magisk, Shizuku and Shadowsocks are optional platform references, not required for the recommended dApp stack.

## Are all resources audited or production-ready?
No. Metadata and commit identity checks are not builds or audits. Each application needs its own executed qualification gates.
