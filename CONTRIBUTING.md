# Contributing

Propose a focused resource with canonical URL, category, role, supported targets, commit, archived status and license provenance. Verify actual coordinates/APIs before adding examples. Do not add mirror wallets, secrets, download trackers, fake badges or unverifiable production claims.

Update catalog/resources.json and README together. Run python3 scripts/check-catalog.py. Include measured build results only when executed, with environment and exact source identity. Preserve upstream attribution.
